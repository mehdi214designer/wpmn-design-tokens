WPMN Component Library

AI-friendly component browser. Copy Prompt gives you a build spec any AI can follow to recreate the component in any stack. Copy Code gives you the full source (JSX + CSS) ready to paste.

For AI agents: fetch registry.json for the machine-readable index, or llms.txt for usage instructions. Raw base URL: https://raw.githubusercontent.com/mehdi214designer/wpmn-design-tokens/master/

Running locally: this page fetches files, so serve it over HTTP (e.g. python3 serve.py or npx serve) instead of opening the file directly.
