# Build Spec: WPMN Section — Product Compare Table

4-product feature comparison matrix: centered header (chip badge, heading, subtext), a fixed-layout table with one 50% feature column and four 12.5% product columns, tri-state status icons (check / minus / cross), and a rounded brand-color highlight ring wrapped around the hero product column. On mobile the table is replaced by stacked per-feature card groups generated by JS from the same data matrix.

The reference implementation is the source of truth. Fetch it and reproduce structure, spacing, and interactions exactly:
`https://raw.githubusercontent.com/mehdi214designer/wpmn-design-tokens/master/sections/product-compare-table/section.html`

## Interaction rules (keep exactly as reference)

- Highlight ring construction (do not replace with a wrapper element): every cell of the hero column carries `position: relative` plus an `::after` overlay with `inset: 0 0 -1px` and 2px left/right borders in `--btn-bg-enable`, `pointer-events: none`, `z-index: 10`. The header cell caps the ring with `inset: 0`, a full 2px border minus `border-bottom`, and `border-radius: var(--radius-lg) var(--radius-lg) 0 0`. The last body row caps the bottom the same way (no `border-top`, radius `0 0 var(--radius-lg) var(--radius-lg)`). The `-1px` bottom inset is what makes adjacent cell borders fuse into one continuous ring.
- Table geometry: `table-layout: fixed`, `border-collapse: collapse`; colgroup widths 50% / 12.5% x4. Header product cells are exactly 94px tall with a stacked 32px logo + name. Body rows separated by 1px `--color-border-primary` top borders, plus a bottom border on the last row. Feature cells pad `16px 16px 16px 0`; status cells pad `18px 16px`, centered.
- Mobile (<768px): the table gets `display: none` and a stacked layout appears — one group per feature (16px label with its 16px feature icon), then one row per product (product mark + name left, status icon right, `10px 16px` padding, 1px `--color-border-primary` border, `--radius-sm`). The hero product row swaps to a 2px `--btn-bg-enable` border. These cards are built by a scoped IIFE from the same FEATURES/PRODUCTS/ICON matrix used by the table — keep the data in one place.
- No hover, scroll, or timed behavior. The section is static apart from the JS mobile build.

## Layout rules (WPMN design guideline)

- Section padding: 96px top/bottom desktop, 64px mobile (<768px). Background `--color-surface-primary`. Section is a flex column with a 48px gap between header and table.
- Header block: max-width 768px centered, text centered. Chip badge ("Comparison"): 24px tall, `--radius-xsm`, background `color-mix(in srgb, var(--color-text-primary) 4%, transparent)`, 1px border at 6% mix, text at 45% mix, body-small medium. Chip-to-heading 12px, heading-to-subtext 16px.
- Heading: `--font-size-h3` / `--font-lh-h3`, `--font-weight-semibold`, `--color-text-primary`, `text-wrap: balance`. Subtext: body-large, `--color-text-secondary`, max-width 448px.
- Table wrap: max-width 1024px centered, side padding 20px desktop, 40px tablet (<1200px), 20px mobile.
- Status colors: yes = `--btn-bg-enable`, partial = `--color-warning-primary`, no = `color-mix(in srgb, var(--color-text-primary) 25%, transparent)`. Hero product mark in `--btn-bg-enable`, competitor marks in `color-mix(in srgb, var(--color-text-secondary) 80%, transparent)`.
- Icons: Hugeicons Pro `stroke.rounded` only, one variant everywhere, inlined as a `<symbol>` sprite with `wpmn-pct-` prefixed ids. 16px feature icons, 20px status icons, 32px product marks (24 viewBox, currentColor).
- Competitor names stay generic (Competitor A/B/C); the hero column is the Fluent product being sold.
- All colors via semantic tokens (`--color-*`, `--btn-bg-*`). Never hardcode brand colors; `data-brand` on any ancestor re-skins the section, including the ring.
- Class scoping: every rule is prefixed with `.wpmn-sec-product-compare-table` so sections can coexist on one page.
- Font: Work Sans via the WPMN typography tokens. Never write raw mobile font-size overrides — the tokens swap at 768px.

## Surface and text pairing (hard rule)

- Light surfaces (`--color-surface-primary`, soft grey fills): headings use `--color-text-primary`, body uses `--color-text-secondary`. Never white or invert text on light surfaces.
- Dark surfaces (`--color-surface-secondary`) and brand-color surfaces (`--color-brand-surface`): headings use `--color-text-primary-invert`, body uses `--color-text-secondary-invert`. Never dark text or dark elements on these surfaces.
- This section sits entirely on light surfaces; the only brand-color paint is the ring borders and status/logo strokes, which carry no text.

## Required token CSS

Load `https://raw.githubusercontent.com/mehdi214designer/wpmn-design-tokens/master/index.css` (primitives -> brand-primitives -> tokens -> typography) before the section markup.

## Output format

A single self-contained `<section class="wpmn-sec-product-compare-table">` containing a scoped `<style>` block, the inline SVG symbol sprite, the markup, and a scoped IIFE `<script>` that resolves its root via `document.currentScript.parentElement` and builds the mobile cards. No external dependencies, no libraries, no hotlinked fonts or images.
